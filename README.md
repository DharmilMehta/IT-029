# Hello World Program

A simple introductory program that prints **"Hello, World!"** to the screen.

## Overview

This project demonstrates basic output syntax in programming. It is often used to verify that a development environment is set up and working properly.

## Code Examples

### Python
```python
print("Hello, World!")
```

### JavaScript
```javascript
console.log("Hello, World!");
```

### C++
```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

## How to Run

1. Copy the code snippet for your preferred language.
2. Save the file with the matching extension (for example, `hello.py` or `hello.js`).
3. Run the file from your terminal or code editor.

## Expected Output

```text
Hello, World!
```
